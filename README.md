# FIT Viewer

React and TypeScript implementation for inspecting local FIT files and selected ZIP entries. Decoding, queries, charts, maps, repair and exports run in a document worker.

## Build

```sh
pnpm install
pnpm run typecheck
pnpm test
pnpm run build
```

## Development server

```sh
pnpm run dev
```

Open at `http://127.0.0.1:5173/`.
